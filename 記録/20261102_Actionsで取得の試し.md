# GitHub Actions から出馬表などが取れるかの試し(2026-11-02)

目的: 提出を「凍結したコードを Actions で動かした出力」にできるか(入力ファイルを手で作る余地をなくす案)。その前提として、Actions のサーバーから必要なページが取れるかを見た。本人「試してみて」。

## やったこと

- 同じ Python スクリプト(標準ライブラリのみ、各ページ 1 回ずつ)を、手元(デスク PC)と Actions(ubuntu-latest、接続元は米国の Microsoft、AS8075)で動かした。
- 試し用のブランチ `actions-probe` に workflow を置いて push で動かし、終わったあとブランチは消した(実行の記録 run 41415768923 は Actions の履歴に残る)。

## 結果(Actions、手元と同じバイト数)

| 取ったもの | 結果 |
|---|---|
| JRA 公式 トップ | 200 |
| JRA 公式 出馬表の入口 → 開催のレース一覧 → 1 レースの出馬表(10/31 東京 1R、17 頭) | 200(POST の cname でたどれた) |
| JRA 公式 過去レース結果検索の入口 | 200 |
| netkeiba 11/1 のレース一覧(race_id 24 件) | 200 |
| netkeiba 出馬表 1 本、db.netkeiba のレース結果 1 本 | 200 |
| 気象庁 予報 JSON(東京) | 200 |

## 分かったこと・分からないこと

- 1 回ずつなら、海外のクラウドからでも JRA 公式・netkeiba・気象庁は止められなかった。
- 未検証: 1 日の全レース・全出走馬の過去成績のように数百回取ったときに止められないか。netkeiba の利用規約で自動取得がどう扱われるか。JRA-VAN(Windows 用ソフト)は Actions では試していない。
- 試したのは月曜で、その週の出馬表はまだ出ていない(木曜ごろ)。取ったのは前の週末の出馬表。
